# SALON STATION — ECサイト体験デモ

[公開デモ](https://acuerdo-sr.github.io/salon-station-demo/) ／ [GitHubリポジトリ](https://github.com/acuerdo-sr/salon-station-demo)

GitHub Pagesで商品検索からテスト注文・管理操作まで体験できます。販売・決済・配送は行いません。

| | GitHub Pages 公開デモ | ローカル版 |
|---|---|---|
| 保存先 | 閲覧者のブラウザのlocalStorage | このPCのSQLite |
| 注文・在庫の共有 | 同じブラウザ内のみ。他の閲覧者とは共有しません | 同じローカルサーバーに接続したブラウザで共有 |
| お届け先 | 架空データに固定 | 架空データの入力・変更を試せます |
| 管理画面 | 操作のシミュレーション | ローカルDBの価格・在庫を更新 |

公開版も実店舗向けの受注システムではなく、機能・デザインのデモです。会員認証・実決済はありません。元のローカルDBや注文データ、ログは公開していません。

## 公開版を更新する

画面は `dist/`、初期商品は `catalog.mjs` を編集し、次を実行します。

```powershell
npm test
npm run build:pages
git add dist catalog.mjs docs
git commit -m "Update demo"
git push
```

GitHub Pagesの公開元は `main` ブランチの `/docs` です。`docs/` は生成物のため直接編集しません。ビルドは公開するファイルを明示的に選び、ローカルDBやログを含めません。

公開版の注文・在庫を初期状態へ戻すには、ブラウザでこのサイトの保存データを削除します。公開側のデモ状態はサイトURLごとのキーで保存されます。

EC-CUBE、CMS、外部CRMを利用せずに作成したサロン向けECサイトの試作です。
Node.js標準HTTPサーバー・標準SQLiteモジュールと、HTML/CSS/JavaScriptで動作します。npmパッケージのインストールやAPIキーは不要です。

## 起動

Node.js 22.13以降が必要です。このPCのNode.js 22.20.0で確認しました。

このフォルダーでターミナルを開き、次を実行します。

```powershell
npm start
```

表示されたURL http://127.0.0.1:4173/ を開きます。停止は、そのターミナルで Ctrl+C です。
`start.ps1` をPowerShellで実行すると、サーバーをバックグラウンドで起動して既定ブラウザーを開きます。実行ポリシーの変更は不要です。スクリプト実行が許可されていないPCでは `npm start` をお使いください。
バックグラウンド起動したサーバーは `stop.ps1` で停止できます。PCの再起動後には自動起動しません。

## 試せること

- 6件の架空の商品、3カテゴリー、キーワード検索、価格順の並べ替え
- 商品詳細、在庫切れ表示、カートへの追加・数量変更・削除
- 入力済みの架空のお届け先 → 注文確認 → テスト注文完了
- 送料660円、商品合計11,000円以上で送料無料（税込）
- 注文履歴、注文による在庫減算
- フッターの「デモ管理画面」から価格・在庫の更新、受注一覧の確認

注文、価格、在庫は `data/shop.sqlite` に保存します。カートは同一ブラウザーのlocalStorageに保存します。
ブラウザーを閉じても注文は残ります。初回起動時のみ初期商品データを投入します。
同じPC・同じサーバーを使う全ブラウザーが同一のデモ会員として注文履歴を共有します。

## テスト

```powershell
npm test
```

独立した一時データベースを使い、送料の境界、数量・価格の不正値、重複注文、在庫不足、同時注文、管理更新、別オリジン拒否、再起動後の永続化を確認します。通常の `data/shop.sqlite` は変更しません。公開版の保存処理も、閲覧者ごとの分離・再読み込み・保存失敗を含めて確認します。

## 構成

- `dist/`：ブラウザー側の画面・画像
- `server.mjs`：商品・見積・注文・商品更新APIとローカルHTTP配信
- `catalog.mjs`：架空の商品データと初期価格・在庫
- `data/shop.sqlite`：初回起動で作成するSQLiteデータベース
- `test/server.test.mjs`：APIの自動テスト
- `dist/api-client.js`：ローカルAPIと公開デモ保存処理の切り替え
- `dist/demo-store.js`：公開版のブラウザ内データ保存処理
- `scripts/build-pages.mjs`：公開用 `docs/` の生成
- `test/demo-store.test.mjs`：公開版の保存処理のテスト

注文確定時にサーバーで価格と在庫を再確認し、注文保存と在庫減算を単一トランザクションで実行します。重複送信時は同じ注文識別子に対し保存済みの注文を返します。
価格改定前に保存した注文の明細は、改定前の価格を保持します。

## 試作の範囲

実決済、会員登録・ログイン、顧客ごとの権限分離、管理者認証、メール、配送連携、請求書、返品・キャンセルは未実装です。カード情報は扱いません。架空データでのみご利用ください。

サーバーは `127.0.0.1` のみに接続を許可します。Host検証と更新APIのOrigin検証を行います。公開運用には認証・権限管理・個人情報保護・決済連携・バックアップ・監視・業務ルール等の追加設計が必要です。この状態で外部公開しないでください。

参照：BEAUTY STATION の公開トップページ https://beauty-station.net/ （2026年9月14日確認）。白地、サロン商材、商品検索、カート、会員向け導線等を参考にした独自の試作です。会員専用画面、内部処理、実際の商品データは再現していません。元サイトの画像・ロゴは複製していません。

商品名・ブランド・価格・説明は架空です。SENAの商品画像3点はこのデモ用のAI生成画像で、同タイプの別商品にも共通画像を使っています。

対応ブラウザーでは、検索とカート1点追加のWebMCPツールを公開します。ツールから注文を確定する機能はありません。

動作確認結果は `検証結果.md` を参照してください。
